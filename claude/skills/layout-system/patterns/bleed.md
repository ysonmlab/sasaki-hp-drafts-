# bleed.md

## 役割
画面幅いっぱい（100vw）に広げるレイアウト。  
Hero、背景色セクション、フルワイドの帯など。

## 判定
- 画面端まで広げたい → **Bleed**
- 画像の上に文字・ボタンを重ねたい → **Bleed + Board（複合）**

## 構造図
```
┌──────────────────────────────────────┐ ← viewport幅 100%
│■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■│   背景（色 or 画像）が端まで
│   ┌──────────────────────────────┐   │
│   │   inner（コンテンツ幅で中央寄せ） │   │
│   └──────────────────────────────┘   │
│■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■│
└──────────────────────────────────────┘
```

## HTML構造
```html
<section class="sect-{name} bleed">
  <div class="bleed__inner u-container">
    <!-- コンテンツ -->
  </div>
</section>
```

## CSS指針
```css
.pg-{page} .sect-{name} {
  width: 100%;        /* 親が padding を持つ場合は 100vw + margin 相殺も可 */
  background: ...;    /* 背景は section に直接 */
}
.pg-{page} .sect-{name} .bleed__inner {
  /* u-container で max-width + margin-inline:auto を継承 */
}
```

## 注意
- 背景は **section（外側）** に、コンテンツ幅制御は **inner（内側）** に分離する
- `100vw` 指定はスクロールバー分の横スクロールに注意。基本は親を画面幅にして `width:100%` で対応する
- 文字を重ねる場合は board.md を併用
