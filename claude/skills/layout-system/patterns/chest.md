# chest.md

## 役割
他のパターンに当てはまらない、自由度の高い汎用コンテナ。  
特殊・未定義のレイアウトの受け皿。

## 判定
- bleed / board / fluid / shelf / tile / rack のいずれにも該当しない → **Chest**

## 構造図
```
┌──────────────────────────────────────┐
│ chest（汎用BOX）                       │
│   レイアウトは内容に応じて個別定義        │
│   ・特殊な配置                          │
│   ・複合パターン                        │
│   ・一点物のデザイン                     │
└──────────────────────────────────────┘
```

## HTML構造
```html
<div class="chest">
  <!-- 任意の構造。必要に応じて命名する -->
</div>
```

## CSS指針
```css
.pg-{page} .sect-{name} .chest {
  /* 個別レイアウトを sect スコープ内で定義 */
}
```

## 注意
- **最終手段**。まず他の6パターンで表現できないか必ず検討する
- 安易に Chest を選ぶと一貫性が崩れる
- 使う場合は `logs/PATTERNS.md` に「なぜ既存パターンで表現できなかったか」を記録する
- 汎用化できそうなら新パターンとして patterns/ に切り出す提案をする
