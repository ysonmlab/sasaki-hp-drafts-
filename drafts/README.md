# drafts/ フォルダ

デザインの**見本（入力）**を置く場所。

- デザインカンプ（PDF / JPG / PNG）・デモHTML を置く。
- 共同作業者が編集する **たたき台HTML** もここに置く（style 込みでOK）。
- ページごとに1ファイル（例：`about.html`、`access.html`）。
- **共同作業者は、このフォルダの中だけを編集する**（他のフォルダは触らない）。
- ここの見本をもとに、オーナーが `docs/workflow-coding.md` に沿って
  最終コードを実装する（HTMLはルート直下、CSSは `assets/css/{page}.css`）。

## 既存HPのリニューアルの場合

既存サイトのソース一式（HTML / CSS / img）がある場合は、`drafts/existing/` に
**フォルダごと丸ごと**置く（参照用・編集しない）。

```
drafts/
  └ existing/        ← 既存HPをまるごとコピー
      ├ index.html
      ├ css/...
      └ img/...
```

- ローカルのHTML/CSSは正確に読めるため、リニューアルの入力として理想的。
- 新しいコードは既存ファイルを直接編集せず、キット規約に沿ってゼロから作り直す
  （古い書き方を引きずらないため）。
- 既存画像のうち**新サイトでも使うもの**は、命名規則に沿って `assets/img/` にコピーする。

---

> 本番でサイトに載せる画像（写真・ロゴ等）は、見本ではなく `assets/img/` に置く。

作業のやり方は `docs/for-collaborators.md` を参照。
